# Age Calculator

A simple Python program that calculates a user's age based on their **year of birth** and **name**.

## Features

* Takes the user's year of birth as input.
* Takes the user's name as input.
* Calculates their age using the year **2026**.
* Displays a personalized age message.

## Code

```python
x = input("Enter your year of birth: ")
y = input("Enter your name: ")

print(f"{y}, your age is {2026 - int(x)}")
```


## Example

```text
Enter your year of birth: 2005
Enter your name: Rahul
Rahul, your age is 21
```

## Requirements

* Python 3.x

No external libraries are required.

## Note

The program uses **2026** as the current year, so the calculated age may need to be updated in future years.
